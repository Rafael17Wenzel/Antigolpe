# Design system inspirado no wireframe Bradesco

Referência de protótipo fornecida: `bradesco_wireframe.html` (histórica). Paleta base: vermelho `#CC0000`, vermelho escuro `#990000`, vermelho claro `#FFECEC`, fundo `#F4F5F7`, texto `#1F2937`, fonte Inter. Usar tokens CSS/Tailwind sem espalhar hex no JSX.

Componentes: cabeçalho, barra de acessibilidade, formulário, alerta, cartões de vaga, lista de cursos, denúncia, simulador de chat e rodapé. Sem copiar elementos que sugiram vínculo oficial não autorizado. Colocar aviso visível de protótipo acadêmico. Diferenciar alertas por ícone+texto, nunca só cor. Modo alto contraste com paleta explícita e verificação WCAG; foco bem visível.

O chat é uma SIMULAÇÃO VISUAL de WhatsApp, sem logos oficiais obrigatórios, sem integração real e sem promessa de leitura de imagens por IA de produção.
